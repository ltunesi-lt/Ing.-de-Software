# USABILIDAD (Usability)
Fuente: `Software Architecture in Practice, 4th Edition` — Ver págs. 252-253 (General Scenario Table). Este archivo resume los valores típicos; validar contra el texto original si está disponible.

La Usabilidad mide qué tan fácil es para el usuario final lograr su objetivo con el sistema, aprender a usarlo, y qué tan bien el sistema lo asiste o previene errores de uso.

## Valores típicos de la General Scenario Table

- **Fuente del estímulo**: usuario final (novato o experto).
- **Estímulo**: el usuario quiere aprender una función del sistema, usarla eficientemente, cometió un error de uso, o necesita ajustar el sistema a sus preferencias/necesidades (accesibilidad).
- **Artefacto**: interfaz de usuario, sistema completo.
- **Ambiente**: primer uso/onboarding, uso rutinario, uso bajo estrés/error, uso con asistencia (accesibilidad).
- **Respuesta**: el sistema provee ayuda contextual/tutorial, deshace o previene la acción errónea (undo, confirmaciones), se adapta a las preferencias del usuario, provee retroalimentación clara del estado.
- **Medida de la respuesta**: tiempo para completar una tarea; cantidad de errores cometidos por el usuario en una sesión; tasa de éxito en completar la tarea sin asistencia; puntaje de satisfacción del usuario (ej. encuesta SUS); tiempo de aprendizaje hasta alcanzar competencia.
